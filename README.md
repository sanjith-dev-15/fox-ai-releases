# Fox AI: Releases

<img src="fox-ai-logo.png" alt="Fox AI logo" width="140" />

**Fox AI** is a private AI assistant for Android that runs **entirely on your phone**. Chats never leave the device, and it works with no internet connection.

This repository only hosts the **APK downloads**. The Fox AI app checks it for updates.

## Install

1. Open the [latest release](https://github.com/sanjith-dev-15/fox-ai-releases/releases/latest) on your phone and download `fox-ai-<version>.apk`.
2. Open the file. If Android asks, allow installing apps from this source.
3. Open Fox AI, go to **Models**, and import a `.gguf` model (for example `Qwen3-0.6B-Q8_0.gguf`).

Requirements: Android 64-bit (arm64), about 1 GB of free RAM and storage for the model. Tested on a Samsung Galaxy M33 5G.

## Updates

Fox AI checks this page for a newer version when it opens (you can turn this off in **Settings → App updates**). Updates keep your chats and models. Android always asks you to confirm the install.

## Privacy

- All AI runs on the phone. No cloud AI, no accounts, no analytics.
- The update check only reads the latest version number from GitHub. No chats or personal data are sent.
